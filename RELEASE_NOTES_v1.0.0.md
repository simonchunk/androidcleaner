# Android Cleaner v1.0.0

First production release of The iPhone Guy Android Cleaner.

## Production release
- Self-contained Windows installer; no Python or Android SDK required on staff PCs.
- Bundled ADB and AAPT2 for device connection and app-name resolution.
- Cleanup, Review, Games, Unused Apps and All Apps workflows.
- Guided app removal and repair-outcome capture.
- Shared Knowledge synchronisation across configured workstations.
- Protected System/OEM apps and explicit removal confirmation.
- GitHub update checking with TLS certificate validation and SHA-256 installer verification.
- Production staff/admin separation and deployment polish validated through the v0.18.x test cycle.

No database schema change is introduced by v1.0.0; existing local knowledge and workstation settings are preserved during upgrade.
