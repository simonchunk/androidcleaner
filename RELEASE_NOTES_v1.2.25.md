# Android Cleaner v1.2.25 — Drivers & Connection

- Staff-accessible Restart ADB command.
- Official Google/Pixel USB driver link from the Advanced menu.
- One-click Device Manager access.
- Built-in Drivers & Connection Help with MTP-vs-ADB guidance.
- Refreshes device detection after restarting ADB.
- Retains v1.2.23 onset discovery changes and v1.2.21/v1.2.22 protected-profile/provenance fixes.
- Includes the v1.2.24 hard shutdown lifecycle fix so AndroidCleaner.exe and adb.exe do not block upgrades.

Google requires acceptance of the Android SDK licence before the USB driver download, so the app opens Google's official driver page rather than redistributing the driver package.
